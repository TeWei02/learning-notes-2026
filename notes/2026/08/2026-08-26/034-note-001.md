# 权限位与 ACL 的叠加：边界条件与异常路径

**日期**：2026-08-26　**领域**：Linux　**编号**：34/5000

## 背景

空集合、极值、超时、部分失败，这几类最容易漏。这里围绕「权限位与 ACL 的叠加」做一次整理，重点放在能直接落地的部分。

## 要点

- 目录的 x 位决定能否进入，读目录内容需要 r
- ACL 生效后 group 权限会显示为 mask
- 边界用例应固化成自动化测试。

## 示例

```bash
setfacl -m u:deploy:rx /srv/app
getfacl /srv/app
```

## 易错点

- umask 会影响新建文件，但不会回收已有权限

## 小结

权限位与 ACL 的叠加 在边界条件与异常路径这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
