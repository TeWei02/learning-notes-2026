# 文件描述符与重定向顺序：并发与线程安全

**日期**：2026-08-26　**领域**：Linux　**编号**：84/5000

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「文件描述符与重定向顺序」做一次整理，重点放在能直接落地的部分。

## 要点

- 2>&1 的位置决定拷贝的是哪个描述符
- exec 3>&1 可保存现场供后续恢复
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```bash
cmd >out.log 2>&1
exec 3>&1 1>tmp.log 2>&1
```

## 易错点

- cmd 2>&1 >f 只把 stderr 指向终端

## 小结

文件描述符与重定向顺序 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
