# ss 与 lsof 定位端口占用：测试与验证策略

**日期**：2026-08-26　**领域**：Linux　**编号**：97/5000

## 背景

测试要覆盖正常、边界与失败三类路径。这里围绕「ss 与 lsof 定位端口占用」做一次整理，重点放在能直接落地的部分。

## 要点

- ss -ltnp 比 netstat 更快且信息完整
- lsof -p 看到进程持有的全部 fd 与文件
- 测试用例本身也要可维护。

## 示例

```bash
ss -ltnp 'sport = :8080'
lsof -i :8080 -sTCP:LISTEN
```

## 易错点

- 容器内 ss 可能看不到宿主机命名空间的连接

## 小结

ss 与 lsof 定位端口占用 在测试与验证策略这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
