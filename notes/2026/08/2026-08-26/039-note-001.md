# 熔断器状态机：边界条件与异常路径

**日期**：2026-08-26　**领域**：系统　**编号**：39/5000

## 背景

空集合、极值、超时、部分失败，这几类最容易漏。这里围绕「熔断器状态机」做一次整理，重点放在能直接落地的部分。

## 要点

- 关闭、打开、半开三态，半开只放少量探测流量
- 基于滑动窗口的失败率比连续失败计数更稳
- 边界用例应固化成自动化测试。

## 示例

```python
if breaker.is_open():
    return fallback()
```

## 易错点

- 熔断恢复过快会导致反复抖动

## 小结

熔断器状态机 在边界条件与异常路径这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
