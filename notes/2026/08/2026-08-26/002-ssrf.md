## 背景

把它放进真实流程，通常要补上配置、日志与失败分支。这里围绕「SSRF 防御要点」做一次整理，重点放在能直接落地的部分。

## 要点

- 禁止访问内网段与元数据地址，解析后再校验 IP
- 重定向与 DNS 重绑定要一并考虑
- 改造后别忘了补一次端到端验证。

## 示例

```python
if ipaddress.ip_address(host).is_private: raise Reject()
```

## 易错点
