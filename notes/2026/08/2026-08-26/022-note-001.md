# TLS 握手耗时拆解：性能与复杂度权衡

**日期**：2026-08-26　**领域**：网络　**编号**：22/5000

## 背景

先量化再优化，凭感觉换实现经常得不偿失。这里围绕「TLS 握手耗时拆解」做一次整理，重点放在能直接落地的部分。

## 要点

- 1-RTT 与 0-RTT 差异在会话复用，0-RTT 有重放风险
- 证书链不完整会导致部分客户端握手失败
- 优化前后都要有可复现的基准数据。

## 示例

```bash
openssl s_client -connect host:443 -servername host -tls1_3
```

## 易错点

- SNI 缺失会拿到默认站点证书

## 小结

TLS 握手耗时拆解 在性能与复杂度权衡这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
