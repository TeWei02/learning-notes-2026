# WebSocket 心跳与重连：并发与线程安全

**日期**：2026-08-26　**领域**：网络　**编号**：86/5000

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「WebSocket 心跳与重连」做一次整理，重点放在能直接落地的部分。

## 要点

- 应用层心跳可穿过多数代理，需与服务端 idle 超时配合
- 重连要带指数退避与抖动，避免雪崩
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```bash
async def heartbeat(ws):
    while True:
        await asyncio.sleep(20)
        await ws.send(b'{"t":"ping"}')
```

## 易错点

- 只在 onclose 里重连会漏掉半开连接

## 小结

WebSocket 心跳与重连 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
