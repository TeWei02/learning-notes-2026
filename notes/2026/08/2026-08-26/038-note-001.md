# 无锁队列的 ABA 问题：边界条件与异常路径

**日期**：2026-08-26　**领域**：并发　**编号**：38/5000

## 背景

空集合、极值、超时、部分失败，这几类最容易漏。这里围绕「无锁队列的 ABA 问题」做一次整理，重点放在能直接落地的部分。

## 要点

- 比较并交换需要版本号或标签位才能识别 ABA
- 内存回收（如 RCU、引用计数）与无锁结构必须一起设计
- 边界用例应固化成自动化测试。

## 示例

```cpp
bool push(Node* n) {
  Node* head = head_.load();
  n->next = head;
  return head_.compare_exchange_weak(head, n);
}
```

## 易错点

- 在 C++ 中用 std::atomic<Node*> 直接 CAS 存在内存回收风险

## 小结

无锁队列的 ABA 问题 在边界条件与异常路径这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
