# 数据倾斜与热点行更新：并发与线程安全

**日期**：2026-08-26　**领域**：数据库　**编号**：87/5000

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「数据倾斜与热点行更新」做一次整理，重点放在能直接落地的部分。

## 要点

- 自增主键写入集中在末尾，分库分表可打散
- 热点账户用分段更新或异步入账缓解行锁
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```sql
UPDATE account SET balance = balance + 1 WHERE id = 7;
```

## 易错点

- 无索引条件更新会升级为表锁级别等待

## 小结

数据倾斜与热点行更新 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
