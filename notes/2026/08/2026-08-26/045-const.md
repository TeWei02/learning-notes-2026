# const 正确性与重载：方案对比与选型

**日期**：2026-08-26　**领域**：C/C++　**编号**：45/5000

## 背景

把候选方案的代价列清楚，选型就不再靠偏好。这里围绕「const 正确性与重载」做一次整理，重点放在能直接落地的部分。

## 要点

- const 成员函数可被 const 对象调用，mutable 允许修改缓存字段
- 按值返回 const 会阻止移动语义
- 选型结论要写清前提，否则换个环境就不成立。

## 示例

```cpp
int cached() const { return cache_; }
void update() { cache_ = compute(); }
```

## 易错点

- 为 const 与非 const 各写一份容易重复，用泛型辅助

## 小结

const 正确性与重载 在方案对比与选型这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
