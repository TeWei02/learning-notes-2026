# 动态规划的滚动数组优化：并发与线程安全

**日期**：2026-08-26　**领域**：算法　**编号**：82/5000

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「动态规划的滚动数组优化」做一次整理，重点放在能直接落地的部分。

## 要点

- 状态只依赖前一层时，倒序更新可把二维压成一维
- 0-1 背包倒序，完全背包正序
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```python
dp = [0] * (cap + 1)
for w, v in items:
    for c in range(cap, w - 1, -1):
        dp[c] = max(dp[c], dp[c - w] + v)
```

## 易错点

- 正序更新会让同一物品被重复使用

## 小结

动态规划的滚动数组优化 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
