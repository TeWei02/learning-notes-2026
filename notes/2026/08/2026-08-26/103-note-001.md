# 幂等重试与退避：测试与验证策略

**日期**：2026-08-26　**领域**：系统　**编号**：103/5000

## 背景

测试要覆盖正常、边界与失败三类路径。这里围绕「幂等重试与退避」做一次整理，重点放在能直接落地的部分。

## 要点

- 重试要区分可重试错误与业务失败
- 加入抖动避免同步重试造成脉冲
- 测试用例本身也要可维护。

## 示例

```python
delay = min(cap, base * 2 ** attempt) * random.uniform(0.8, 1.2)
```

## 易错点

- 对写接口无限重试会放大故障

## 小结

幂等重试与退避 在测试与验证策略这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
