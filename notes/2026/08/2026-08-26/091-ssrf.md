# SSRF 防御要点：并发与线程安全

**日期**：2026-08-26　**领域**：安全　**编号**：91/5000

## 背景

共享可变状态是并发问题的根源，能消除就消除。这里围绕「SSRF 防御要点」做一次整理，重点放在能直接落地的部分。

## 要点

- 禁止访问内网段与元数据地址，解析后再校验 IP
- 重定向与 DNS 重绑定要一并考虑
- 并发缺陷难以复现，需靠压测与竞态注入暴露。

## 示例

```python
if ipaddress.ip_address(host).is_private: raise Reject()
```

## 易错点

- 只做字符串前缀过滤会被绕过

## 小结

SSRF 防御要点 在并发与线程安全这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
