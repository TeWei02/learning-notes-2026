# JWT 校验的必查项：边界条件与异常路径

**日期**：2026-08-26　**领域**：安全　**编号**：40/5000

## 背景

空集合、极值、超时、部分失败，这几类最容易漏。这里围绕「JWT 校验的必查项」做一次整理，重点放在能直接落地的部分。

## 要点

- 校验签名算法、签发者、受众与过期时间
- 不要信任未校验的头部信息
- 边界用例应固化成自动化测试。

## 示例

```python
jwt.decode(token, key, algorithms=['RS256'], audience='api')
```

## 易错点

- 接受 alg=none 是经典漏洞

## 小结

JWT 校验的必查项 在边界条件与异常路径这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
