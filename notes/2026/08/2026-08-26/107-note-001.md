# 并查集路径压缩与按秩合并：重构与可维护性

**日期**：2026-08-26　**领域**：算法　**编号**：107/5000

## 背景

先把行为固定住再改结构，避免同时改两件事。这里围绕「并查集路径压缩与按秩合并」做一次整理，重点放在能直接落地的部分。

## 要点

- find 递归写路径压缩，union 按秩合并保证树高近似对数
- 带权并查集需要在 find 中同步更新权值
- 重构后接口不变，调用方无感。

## 示例

```python
def find(x):
    while x != p[x]:
        p[x] = p[p[x]]
        x = p[x]
    return x
```

## 易错点

- 只压缩不按秩合并也能均摊很优，但最坏情况退化

## 小结
