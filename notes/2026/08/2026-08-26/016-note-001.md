# 可观测性三支柱关联：常见陷阱与错误示范

**日期**：2026-08-26　**领域**：工具　**编号**：16/5000

## 背景

多数线上问题不是不会用，而是用错了一个细节。这里围绕「可观测性三支柱关联」做一次整理，重点放在能直接落地的部分。

## 要点

- 用 trace id 把日志、指标、链路串起来
- 指标看趋势，链路看个案，日志看细节
- 把踩过的坑写成检查项，比背结论更有效。

## 示例

```yaml
log.info('order ok', extra={'trace': trace_id})
```

## 易错点

- 缺少 trace 关联会让排障退化为翻日志

## 小结

可观测性三支柱关联 在常见陷阱与错误示范这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
