## 背景

它很少单独出现，和上下游的约定决定了整体效果。这里围绕「序列化性能与安全性」做一次整理，重点放在能直接落地的部分。

## 要点

- pickle 反序列化不可信数据等于执行任意代码
- 跨语言场景用 JSON 或 msgpack，注意浮点与时间精度
- 跨组件问题先在边界处抓包或打日志。

## 示例

```python
import json
payload = json.dumps(rec, ensure_ascii=False, separators=(',', ':'))
```

## 易错点

- 默认 ensure_ascii=True 会让中文体积翻三倍

## 小结

序列化性能与安全性 在与相邻技术的配合这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
