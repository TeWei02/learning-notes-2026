## 背景

复盘只谈事实与改进项，不追责个人。这里围绕「滑动窗口求最长子串」做一次整理，重点放在能直接落地的部分。

## 要点

- 窗口右移扩张、左移收缩，每次收缩后检查条件
- 出现次数用数组或哈希表，注意清理零计数键
- 每个改进项都要有负责人与截止时间。

## 示例

```python
cnt = {}
l = best = 0
for r, ch in enumerate(s):
    cnt[ch] = cnt.get(ch, 0) + 1
    while cnt[ch] > 1:
        cnt[s[l]] -= 1
        l += 1
    best = max(best, r - l + 1)
```

## 易错点

- 条件写成 while 而非 if，否则窗口收缩不彻底
