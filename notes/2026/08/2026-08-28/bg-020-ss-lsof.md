# ss 与 lsof 定位端口占用：与相邻技术的配合

**日期**：2026-08-28　**领域**：Linux　**编号**：20/9000

## 背景

它很少单独出现，和上下游的约定决定了整体效果。这里围绕「ss 与 lsof 定位端口占用」做一次整理，重点放在能直接落地的部分。

## 要点

- ss -ltnp 比 netstat 更快且信息完整
- lsof -p 看到进程持有的全部 fd 与文件
- 跨组件问题先在边界处抓包或打日志。

## 示例

```bash
ss -ltnp 'sport = :8080'
lsof -i :8080 -sTCP:LISTEN
```

## 易错点

- 容器内 ss 可能看不到宿主机命名空间的连接

## 小结

ss 与 lsof 定位端口占用 在与相邻技术的配合这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
