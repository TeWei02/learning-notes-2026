## 要点

- 长期分支合并回主干的冲突成本随时间线性增长
- 短分支 + 频繁集成能显著降低合并风险
- 把排查过程留成记录，下次能少走弯路。

## 示例

```bash

git rebase origin/main
```

## 易错点
