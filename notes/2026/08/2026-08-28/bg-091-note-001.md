# 滑动窗口求最长子串：边界条件与异常路径

**日期**：2026-08-28　**领域**：算法　**编号**：91/9000

## 背景

空集合、极值、超时、部分失败，这几类最容易漏。这里围绕「滑动窗口求最长子串」做一次整理，重点放在能直接落地的部分。

## 要点

- 窗口右移扩张、左移收缩，每次收缩后检查条件
- 出现次数用数组或哈希表，注意清理零计数键
- 边界用例应固化成自动化测试。

## 示例

```python
cnt = {}
l = best = 0
for r, ch in enumerate(s):
    cnt[ch] = cnt.get(ch, 0) + 1
    while cnt[ch] > 1:
        cnt[s[l]] -= 1
        l += 1
    best = max(best, r - l + 1)
```

## 易错点

- 条件写成 while 而非 if，否则窗口收缩不彻底

## 小结

滑动窗口求最长子串 在边界条件与异常路径这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
