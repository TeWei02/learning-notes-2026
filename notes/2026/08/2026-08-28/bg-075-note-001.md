# 单调栈求下一个更大元素：常见陷阱与错误示范

**日期**：2026-08-28　**领域**：算法　**编号**：75/9000

## 背景

多数线上问题不是不会用，而是用错了一个细节。这里围绕「单调栈求下一个更大元素」做一次整理，重点放在能直接落地的部分。

## 要点

- 栈内维护递减序列，弹出时即确定右侧第一个更大值
- 循环数组需要遍历两遍并取模
- 把踩过的坑写成检查项，比背结论更有效。

## 示例

```python
stack = []
res = [0] * n
for i, x in enumerate(a):
    while stack and a[stack[-1]] < x:
        res[stack.pop()] = x
    stack.append(i)
```

## 易错点

- 忘记把未弹出的下标置为 -1 会留下默认值

## 小结

单调栈求下一个更大元素 在常见陷阱与错误示范这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
