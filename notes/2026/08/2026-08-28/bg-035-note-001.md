# 双指针处理有序数组去重：小规模验证方法

## 背景

先用小样本验证假设，再决定是否推广。这里围绕「双指针处理有序数组去重」做一次整理，重点放在能直接落地的部分。

## 要点

- 快慢指针原地覆盖，慢指针指向已确定的最后一个合法位置
- 返回长度而非新数组，调用方只读前 k 个
- 试点结论要能复现。

## 示例

```python
k = 0
for x in a:
    if k == 0 or x != a[k - 1]:
        a[k] = x
        k += 1
```

## 易错点

- 比较对象是已写入的值而不是原数组前一位

## 小结

双指针处理有序数组去重 在小规模验证方法这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
