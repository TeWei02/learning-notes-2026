# find 与 grep 的组合排查：代价与适用边界

**日期**：2026-08-28　**领域**：Linux　**编号**：28/9000

## 背景

任何方案都有不适用的时候，提前写清楚。这里围绕「find 与 grep 的组合排查」做一次整理，重点放在能直接落地的部分。

## 要点

- find 用 -print0 配合 xargs -0 处理含空格文件名
- grep -r 前先用 find 缩小范围能省大量 IO
- 把不适用条件写进文档，避免误用。

## 示例

```bash
find . -name '*.log' -mtime -1 -print0 | xargs -0 grep -l ERROR
```

## 易错点

- xargs 默认按空白分割，遇到空格文件会断
