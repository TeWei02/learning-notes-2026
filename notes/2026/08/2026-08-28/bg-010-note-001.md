# 二分查找的三种边界写法：配置与参数调优

**日期**：2026-08-28　**领域**：算法　**编号**：10/9000

## 背景

参数调整必须一次只改一个，否则无法归因。这里围绕「二分查找的三种边界写法」做一次整理，重点放在能直接落地的部分。

## 要点

- 闭区间写法 lo<=hi，左闭右开写法 lo<hi，混用会导致死循环
- 求下界用 lower_bound，避免返回命中即返回
- 调优结论要绑定当时的负载特征。

## 示例

```python
lo, hi = 0, len(a)
while lo < hi:
    mid = (lo + hi) // 2
    if a[mid] < target:
        lo = mid + 1
    else:
        hi = mid
return lo
```

## 易错点

- mid 计算用 lo+(hi-lo)//2 可避免整型溢出

## 小结

二分查找的三种边界写法 在配置与参数调优这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
