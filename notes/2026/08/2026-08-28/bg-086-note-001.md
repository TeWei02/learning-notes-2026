# 事务隔离级别与幻读：性能与复杂度权衡

**日期**：2026-08-28　**领域**：数据库　**编号**：86/9000

## 背景

先量化再优化，凭感觉换实现经常得不偿失。这里围绕「事务隔离级别与幻读」做一次整理，重点放在能直接落地的部分。

## 要点

- RR 下间隙锁可避免幻读，但会带来更多锁等待
- RC 下同一事务内两次读可能不一致
- 优化前后都要有可复现的基准数据。

## 示例

```sql
SET SESSION TRANSACTION ISOLATION LEVEL READ COMMITTED;
START TRANSACTION;
```

## 易错点

- 长事务会拖住 undo 清理，务必控制时长

## 小结

事务隔离级别与幻读 在性能与复杂度权衡这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
