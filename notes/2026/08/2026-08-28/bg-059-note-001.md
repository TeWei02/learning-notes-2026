# 动态规划的滚动数组优化：实现原理与内部机制

**日期**：2026-08-28　**领域**：算法　**编号**：59/9000

## 背景

知道底层怎么走，行为异常时才能判断卡在哪一层。这里围绕「动态规划的滚动数组优化」做一次整理，重点放在能直接落地的部分。

## 要点

- 状态只依赖前一层时，倒序更新可把二维压成一维
- 0-1 背包倒序，完全背包正序
- 原理清楚后，参数上限与限制条件基本能自己推导。

## 示例

```python
dp = [0] * (cap + 1)
for w, v in items:
    for c in range(cap, w - 1, -1):
        dp[c] = max(dp[c], dp[c - w] + v)
```

## 易错点

- 正序更新会让同一物品被重复使用

## 小结

动态规划的滚动数组优化 在实现原理与内部机制这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
