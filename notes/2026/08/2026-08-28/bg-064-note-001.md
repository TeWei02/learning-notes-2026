# 熔断器状态机：实现原理与内部机制

**日期**：2026-08-28　**领域**：系统　**编号**：64/9000

## 背景

知道底层怎么走，行为异常时才能判断卡在哪一层。这里围绕「熔断器状态机」做一次整理，重点放在能直接落地的部分。

## 要点

- 关闭、打开、半开三态，半开只放少量探测流量
- 基于滑动窗口的失败率比连续失败计数更稳
- 原理清楚后，参数上限与限制条件基本能自己推导。

## 示例

```python
if breaker.is_open():
    return fallback()
```

## 易错点

- 熔断恢复过快会导致反复抖动

## 小结

熔断器状态机 在实现原理与内部机制这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
