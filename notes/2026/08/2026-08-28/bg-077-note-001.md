# 权限位与 ACL 的叠加：常见陷阱与错误示范

**日期**：2026-08-28　**领域**：Linux　**编号**：77/9000

## 背景

多数线上问题不是不会用，而是用错了一个细节。这里围绕「权限位与 ACL 的叠加」做一次整理，重点放在能直接落地的部分。

## 要点

- 目录的 x 位决定能否进入，读目录内容需要 r
- ACL 生效后 group 权限会显示为 mask
- 把踩过的坑写成检查项，比背结论更有效。

## 示例

```bash
setfacl -m u:deploy:rx /srv/app
getfacl /srv/app
```

## 易错点

- umask 会影响新建文件，但不会回收已有权限

## 小结

权限位与 ACL 的叠加 在常见陷阱与错误示范这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
