# ss 与 lsof 定位端口占用：配置与参数调优

**日期**：2026-08-27　**领域**：Linux　**编号**：12/9000

## 背景

参数调整必须一次只改一个，否则无法归因。这里围绕「ss 与 lsof 定位端口占用」做一次整理，重点放在能直接落地的部分。

## 要点

- ss -ltnp 比 netstat 更快且信息完整
- lsof -p 看到进程持有的全部 fd 与文件
- 调优结论要绑定当时的负载特征。

## 示例

```bash
ss -ltnp 'sport = :8080'
lsof -i :8080 -sTCP:LISTEN
```

## 易错点

- 容器内 ss 可能看不到宿主机命名空间的连接

ss 与 lsof 定位端口占用 在配置与参数调优这一面，结论可以归纳为：把前提写清楚、把失败路径覆盖到，剩下的就是按数据调优。
