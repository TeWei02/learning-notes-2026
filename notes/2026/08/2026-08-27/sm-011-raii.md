## 背景

参数调整必须一次只改一个，否则无法归因。这里围绕「RAII 与资源释放顺序」做一次整理，重点放在能直接落地的部分。

## 要点

- 析构按构造逆序执行，成员按声明顺序构造、逆序析构
- 异常路径同样会析构，这正是 RAII 的价值
- 调优结论要绑定当时的负载特征。

## 示例

```cpp
struct File {
    FILE* f;
    File(const char* p) : f(fopen(p, "r")) {}
    ~File() { if (f) fclose(f); }
};
```
